1. Overview视觉哲学与设计意图

本设计系统是一条穿透噪声的信号——一道电子黄色频率扫过纯黑底面，每一个数据点都是一次播报。它不是界面，是仪器。工程师坐在这块屏幕前，读取数字，做决策，离开。

视觉语言起点是终端美学：近黑底面三层堆叠，全部带有极微弱的暖黄色调——电子黄主色的余温渗进了整个中性色调栈。这不是"深色主题"，是一套发光体系：背景吸光，数字发光。

本系统明确拒绝：SaaS 营销系的渐变堆砌；厚重企业感（SAP / Oracle）的蓝灰主色；任何浅色底面的诱惑。这是工程师为工程师构建的工具。

Key Characteristics

  • 近黑三层底面，带统一的暖黄余温
  • 单一主色频率：#faff69 用于信号，不用于装饰
  • 信息密度优先，余白服务于扫读而非审美
  • 数值永远用等宽字体（JetBrains Mono）
  • 交互有重量感：hover/active 状态明确

The Single Frequency Rule

Electric Volt (#faff69) 在任意屏幕上的覆盖面积不超过 5%。它的稀缺性是它作为信号的原因。出现在三个以上视觉区域时必须审查——可能有一处是装饰，不是信号。

The Warm Stack Rule

所有中性色（底面 → 浮层 → 暖板 → 导航激活底）都带有对齐 Electric Volt 色调的微量暖偏色。新增中性色层次时，必须沿这条暖轴插值，不得添加冷灰或蓝灰色。

The Mono-for-Numbers Rule

任何数值（统计数字、百分比、行号、时间戳数字部分）都使用 JetBrains Mono 渲染。等宽是数字可读性的前提，不因"看起来一致"而改为 Inter。

The Fixed Scale Rule

字号固定（px），不使用 clamp() 或 vw 单位。仪表盘用户在固定 DPI 下操作，流式字号在侧边栏或窄面板中产生视觉噪声。

4. Elevation纯色调分层——无任何 box-shadow，深度由底面色阶和 border 传达

系统严格使用色调分层替代阴影。三层结构（由深到浅）：

底面层
Void · #0a0a0a · 页面画布
内容层
Surface · #101010 · 卡片、Panel
导航层
Panel · #14140b · 侧边栏、顶栏

唯一分隔工具：rgba(255,255,255,0.08) 边界线，在三层任意组合中保持一致重量。

The No-Shadow Rule

禁止使用任何 box-shadow。层次感来自色阶，投影会破坏终端美学的纯净感。

The Flat-By-Default Rule

表面在静止状态完全平坦。状态变化来自背景色切换（hover: #171717；active: #222222），不通过投影或模糊表示激活。

6. Do's and Don'tsPRODUCT.md 的策略线在这里落地为视觉守则

Do

  • 用 Electric Volt (#faff69) 表示信号：激活态、交互 hover、需要注意的读数
  • 数值永远用 JetBrains Mono（统计数字、百分比、行号、时间戳数字）
  • 新增中性色时沿暖黄色轴插值，不添加冷灰或蓝灰色
  • 状态变化通过背景色切换表达，不用阴影或模糊
  • 错误状态比成功状态更醒目——bad-text (#ffb4ab) 这是对的
  • 页面切换使用 opacity + translate + blur 过渡（300ms），并响应 prefers-reduced-motion
  • 用 rgba(255,255,255,0.08) 作为唯一边框颜色，不用实心颜色

Don't

  • SaaS 营销系设计（渐变堆砌、五彩斑斓插图、大面积圆角卡片网格）
  • 厚重企业感（SAP / Oracle 蓝灰主色、多层 Tab 嵌套、宽实线边框）
  • 浅色或白色底面——任何 L > 0.2 的背景色都背离终端信号美学
  • 任何 box-shadow——深度来自色阶，不来自投影
  • 在三个以上位置同时使用 Electric Volt，审查是否有装饰性用法
  • 为装饰目的使用 backdrop-filter / 毛玻璃效果
  • border-left > 1px 的彩色竖条做卡片或列表的视觉强调
  • 渐变文字（background-clip: text + gradient）
  • 在 UI 标签、按钮、数据单元格中使用 Display 字体
  • 在不表示数据序列的地方用编号标记（01 / 02 / 03 眉头样式）
